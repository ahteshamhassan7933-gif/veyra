One-click OpenAI Agentic Commerce Protocol + Google AP2 support for WooCommerce. Sell inside ChatGPT, Perplexity, Gemini.

== Description ==

Veyra exposes the five OpenAI Instant Checkout endpoints on your WooCommerce store, signed with your API key, so AI agents can complete purchases without leaving the chat.

Free tier: proxy to Veyra hosted endpoint (rate-limited, 100 sessions/mo).
Pro tier: unlimited sessions, priority routing, Merchant Center hygiene, AI-visibility tracker. See https://veyra.dev/pricing.

== Installation ==

1. Install and activate plugin.
2. Get API key at https://veyra.dev/signup.
3. Settings → Veyra ACP → paste key.
4. Submit your store to OpenAI at https://chatgpt.com/merchants.
